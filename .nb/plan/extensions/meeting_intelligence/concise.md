# Layerable Extension Plan: Meeting Intelligence & Auto-Transcription

### Executive Overview
The **Meeting Intelligence Extension** integrates calendar detection, local consent-verified audio recording, on-device Whisper speech-to-text, acoustic speaker diarization, and autonomous action item extraction into Personal OS. It bridges interactions from meetings directly into the Projects pillar (action item tasks), Thoughts pillar (meeting debriefs and wikilinks), and Interactions pillar (CRM touchpoint history).

## 2. Audio Pipeline & Data Schema

### 2.1. Audio & Diarization Pipeline
1. **Consent Verification**: Audio recording only activates if configured or if calendar event title/description confirms consent.
2. **Audio Capture**: 16kHz mono WAV stream buffered via `cpal` or virtual audio loopback.
3. **Local Whisper Transcription**: Segment-level timestamping (using quantized `whisper.cpp` model running locally).
4. **Voiceprint Diarization**: 256-dimensional acoustic speaker embeddings clustered via agglomerative hierarchical clustering to attribute utterances to participants.

### 2.2. SQLite Meeting Schema
```sql
CREATE TABLE IF NOT EXISTS meetings (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    calendar_event_id TEXT REFERENCES activities(id),
    platform TEXT NOT NULL CHECK (platform IN ('zoom', 'google_meet', 'teams', 'in_person', 'other')),
    started_at DATETIME NOT NULL,
    ended_at DATETIME,
    audio_blake3_hash TEXT,
    summary_markdown TEXT,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS meeting_utterances (
    id TEXT PRIMARY KEY,
    meeting_id TEXT NOT NULL REFERENCES meetings(id) ON DELETE CASCADE,
    speaker_id TEXT, -- resolved contact_id if identified
    speaker_label TEXT NOT NULL, -- e.g. "Speaker 1"
    start_ms INTEGER NOT NULL,
    end_ms INTEGER NOT NULL,
    text TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS meeting_action_items (
    id TEXT PRIMARY KEY,
    meeting_id TEXT NOT NULL REFERENCES meetings(id) ON DELETE CASCADE,
    description TEXT NOT NULL,
    assignee_contact_id TEXT REFERENCES contacts(id),
    project_task_id TEXT REFERENCES project_tasks(id),
    deadline DATETIME,
    status TEXT NOT NULL DEFAULT 'open' CHECK (status IN ('open', 'completed', 'dismissed'))
);
```

## 3. Privacy & Invariant Enforcers

1. **Local Audio Storage Invariant**: Raw audio files and intermediate spectral data NEVER leave the local host. All transcription occurs on-device via Whisper.cpp.
2. **PII Egress Redaction**: Before sending meeting summaries or transcripts to remote Tier A models for executive summaries, PII must pass through the `PrivacyCoordinator` (`GAP-004`).
3. **One-Click Email Approval**: Follow-up email drafts generated by `agent_transcript_analyzer` are strictly staged in `user/hitl/meeting_followup_queue.md` and cannot be sent autonomously.
